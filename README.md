Descripción del Proyecto 

Iberá AR  es una experiencia inmersiva de realidad aumentada (AR) diseñada para enriquecer la visita al museo del Iberá , una región emblemática de Argentina conocida por su biodiversidad única. A través de esta aplicación, los visitantes pueden interactuar con paneles informativos físicos y desbloquear contenido digital interactivo, como modelos 3D y audiovisuales, que complementan la experiencia educativa y cultural. 

El objetivo principal de Iberá AR  es combinar tecnología avanzada con la conservación del patrimonio natural, ofreciendo una herramienta innovadora que educa, entretiene e inspira a los usuarios a conectarse con la flora y fauna autóctona de la región. 
Características Principales 

    Escaneo de Paneles Interactivos : Los visitantes pueden escanear postas físicas distribuidas en el museo para activar experiencias de realidad aumentada.
    Modelos 3D Realistas : Cada panel desbloquea un modelo 3D detallado de especies nativas, animado y optimizado para dispositivos móviles.
    Audiovisuales Contextuales : Se incluyen audios temáticos y efectos sonoros que complementan la narrativa visual de cada especie.
    Interacción Intuitiva : Los usuarios pueden rotar, acercar y explorar los modelos 3D en tiempo real, mejorando la experiencia de aprendizaje.
    Compatibilidad Multiplataforma : La aplicación está diseñada para funcionar sin problemas en dispositivos móviles modernos, aprovechando tecnologías web como AR y WebGL.
     

Tecnologías Utilizadas 

Este proyecto utiliza las siguientes tecnologías y herramientas clave: 

    A-Frame  : Framework web para crear experiencias de realidad virtual y aumentada.
    MindAR  : Biblioteca de AR basada en marcadores para la detección precisa de imágenes.
    Three.js  : Motor de renderizado 3D utilizado para gestionar modelos y luces.
    GLTF/GLB : Formato optimizado para modelos 3D, asegurando un rendimiento eficiente en dispositivos móviles.
    HTML5/CSS3/JavaScript : Lenguajes fundamentales para la estructura, diseño y funcionalidad del proyecto.
    GitHub Pages : Plataforma de hosting para la distribución del proyecto.
     

Instalación y Uso 
Requisitos Previos 

    Un dispositivo móvil con acceso a una cámara y navegador compatible (Chrome, Firefox, Safari).
    Conexión a internet para cargar los recursos multimedia.
     

Pasos para Usar la Aplicación 

    Acceso : Abre la aplicación en tu navegador a través del enlace proporcionado (hosteado en GitHub Pages).
    Permisos : Permite el acceso a la cámara cuando se te solicite.
    Explora : Escanea cualquiera de los paneles interactivos disponibles en el museo para desbloquear la experiencia de AR.
    Interactúa : Explora los modelos 3D, activa los audios y descubre información sobre las especies nativas.
